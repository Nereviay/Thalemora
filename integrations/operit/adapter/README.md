使用官方 `Tools.Net.http`，连接/读取各 2 秒；宿主另有整条 Hook 链超时。这不是对整体聊天固定 2 秒的承诺。API 错误或空结果保持原消息，日志不记录 token 或召回正文。只验证本次合成、假模型请求；不把它扩大为所有版本或客户端兼容。
