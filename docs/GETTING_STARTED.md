# 第一次使用洄海

你需要先运行洄海服务，再决定是否连接聊天软件。**第一次体验不需要购买模型 API。**

## 1. 安装并打开管理台

按设备选择：[Windows](INSTALL_WINDOWS.md) · [Linux / 服务器](INSTALL_LINUX.md) · [Android](INSTALL_ANDROID.md)。

启动后，在运行服务的那台设备上打开 `http://127.0.0.1:8765`。如果服务在另一台设备，使用它的可访问地址，或按 Linux 教程建立连接通道。

管理台需要安装时设置的 `THALEMORA_TOKEN`，它相当于这个实例的管理员密码。保存好它，下次启动仍使用原密钥。

## 2. 安装后先做这四件事

1. **注册一个 AI**：在界面中叫作 Agent，可以填“旅行助手”。它决定记忆归属于谁。
2. **授权来源**：练习时使用 `demo-app`、通道 `main`。来源就是聊天记录来自哪个应用；私人通道需要另外授权。
3. **导入练习记录**：在「历史与原话」导入[示例文件](examples/p4_history.json)，搜索“旅行计划”。
4. **保存一条人工记忆**：找到原话后点「原文存为人工记忆」，再到 Memory 查看内容和来源。

导入是保存历史；不会自动把每句话都变成长期记忆。手工记忆不依赖模型，自动整理则需要另外配置。

## 4. 让聊天软件使用记忆

- **SillyTavern / Operit**：按[插件教程](PLUGIN_SETUP.md)安装，填写服务地址和专用召回凭据。
- **其他支持 MCP 的软件**：按 [MCP 教程](MCP.md)连接，再在目标助手中启用记忆工具。
- **自己的应用**：按[应用接入说明](INTEGRATION.md)调用接口。

这不会自动抓取新聊天记录。聊天同步需要来源应用单独接线。

## 5. 想自动整理历史？

阅读[模型与后台整理](AUTOMATIC_MEMORY.md)。你可以分别配置整理、筛选和反思模型；也能单独选择向量检索与重排方式。

先少量导入、查看结果，再处理自己的完整历史。关闭模型仍能浏览、搜索和手工管理。

## 常见情况

| 情况 | 先检查什么 |
| --- | --- |
| 网页打不开 | 服务是否仍在运行；地址是否指向实际运行服务的设备。 |
| 登录提示 401 | 管理密钥是否与当前服务一致。 |
| 注册成功但不能导入 | 是否授权了示例使用的 `demo-app/main`。 |
| 有原话却没有自动记忆 | 是否配置并启动后台整理；新内容会先按经历分段，不保证立刻提炼。 |
| 工具连上却没在聊天使用 | 是否在目标助手中启用 MCP；模型不保证每轮调用。 |
| 插件没有加入记忆 | 是否使用专用召回凭据、开关已保存、服务可达，以及消息是否超过 200 字符。 |

记忆数据保存在启动时的 `--data` 目录。不要为了更新而删除它；升级前按[维护说明](MAINTENANCE.md)备份。
