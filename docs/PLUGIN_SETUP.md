# 酒馆 / Operit 插件安装与配置

插件 **0.2.0** 已完成本地实现、包装和最低验收，尚未公开。酒馆配置通过本机浏览器合成宿主验证；Operit 新设置页已在原 Android 17 / 官方 v1.12.2 通过普通导入、保存及 App 重开回读。原 P8 两宿主召回实证沿用，不重复整套手机测试。

## 先准备同一套洄海服务

1. 服务需包含 P8 召回接口；当前核心候选为 0.7.0.dev1，公开 v0.6.0 不支持。
2. 注册目标 Agent、授权来源与通道，再由可信管理端签发专用召回 token；完整合同见 [召回协议](P8_RECALL_CONNECTOR.md)。
3. 明确服务运行在哪台设备。手机 `127.0.0.1` 只代表手机自身，不能代替 VPS 地址。

插件只填**服务根地址 + 专用召回凭据 + 启用开关**，不接收管理密钥或模型 Key。插件只在发送前读取记忆，不把新聊天自动同步回洄海。

## 出问题时

- 找不到设置：先确认装的是 0.2.0、目录层级正确且插件已启用；旧 Operit 实验 ID 不会自动变成新 ID。
- 服务地址正确但召回失败：检查专用凭据、来源授权、可达性与浏览器跨源条件。酒馆设置区显示本轮状态，Operit 使用宿主日志；不把失败伪装为召回成功。
- 确认酒馆页面 Origin 与服务端 `THALEMORA_RECALL_CORS_ORIGIN` 精确一致；不为接入而放开通配跨源规则。
- 想停用：关闭开关并保存；不再使用时可在服务端撤销凭据。关闭召回不删除记忆或原聊天。

原酒馆 6 场景、Operit 最小同轮注入已通过；纯手机首装、长期后台和聊天后自动同步仍未因此完成。本轮不公开发新版或升级念念。
