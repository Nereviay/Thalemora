# 安装聊天插件

v0.7.0 提供 **SillyTavern 和 Operit 插件适配**。两个插件版本均为 0.2.0，从[新版下载页](https://github.com/yuyu1838309000-cmd/Thalemora/releases/tag/v0.7.0)获取。

## 先准备三样东西

1. **正在运行的洄海 v0.7.0 服务**，可装在电脑、服务器或支持的工作区。
2. **服务根地址**，例如 `https://你的洄海地址`，不要加 `/api/recall`。
3. **专用召回凭据**，由洄海服务管理者为目标 AI 和来源生成。自部署用户按[生成凭据](RECALL_API.md#生成和撤销召回凭据)操作。

不要填写管理密钥或聊天模型 Key。插件凭据只用于读取绑定来源的相关记忆。

## SillyTavern 1.19.0

1. 下载 `thalemora-sillytavern-0.2.0.zip`。
2. 在运行酒馆的设备上解压，把包内文件放到：

   ```text
   data/<user-handle>/extensions/thalemora-recall/
   ```

   `<user-handle>` 是酒馆用户目录。确保 `manifest.json` 直接位于 `thalemora-recall` 下，不要多套一层文件夹。

3. 刷新酒馆，确认扩展启用；进入扩展设置，展开「洄海 · 自动召回」。
4. 填地址与专用凭据，勾选开关，点「保存设置」。

这个 ZIP 使用文件安装，不能把洄海仓库根 URL 当作独立扩展 URL 粘进安装框。

**保存方式：** 地址和开关保存在酒馆设置里；凭据只在当前标签页保存，刷新仍在，关页后需重填。取消开关并保存会立即清空本插件的注入内容。

### 浏览器跨设备连接

若酒馆页面与洄海不在同一 Origin，需要在洄海进程环境设置：

```bash
export THALEMORA_RECALL_CORS_ORIGIN="https://你的酒馆地址"
```

填写精确的协议、主机和端口，不带路径、不用通配符。若通过 Docker 运行，还需把该变量加入容器环境。此设置允许该网页发起跨源请求，不替代服务端认证。

HTTPS 页面请求 HTTP 服务可能被浏览器阻止；远程连接请提供 HTTPS 或可信网络通道。保存后，设置区会显示本轮召回、空结果或失败状态。

## Operit 1.12.2

1. 下载 `thalemora-operit-0.2.0.toolpkg` 到手机。
2. 打开 Operit「包管理」，选择「插件」分类，点「导入外部插件」并选择文件。
3. 启用「洄海 · 自动召回」。
4. 在「工具箱」打开同名设置页，填服务地址、专用凭据和开关，点「保存设置」。

设置保存在 Operit 本机 App 配置中，重开后继续使用；密码字段会遮挡凭据。无需 Root、Shizuku、无障碍、定位或通知权限。

插件 ID 为 `org.thalemora.recall`。若你自己曾安装旧实验包 `org.thalemora.operit_probe`，先停用它，避免重复召回。

## 怎样使用和停用？

正常发消息即可。插件先找相关记忆，再继续原模型请求；没有匹配可以返回空，失败或超时也继续聊天。

- 只把资料放入本轮模型请求，不改用户原话、不代理聊天模型。
- 消息超过 200 个 Unicode 字符时不截断，跳过该轮召回。
- 酒馆等待约 2 秒；Operit 的连接/读取各 2 秒，宿主还可能有整轮等待限制。
- 关闭开关并保存即可停用。要忘记凭据，关闭、清空字段并保存；不再使用时也可在服务端撤销。
- 两个插件不自动保存新聊天，也不包含记忆服务本身。

适配范围是上面列出的宿主版本；其他版本如接口变化，需要对应调整。Android 运行服务与后台限制见[手机说明](INSTALL_ANDROID.md)。
