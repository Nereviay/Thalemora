# 洄海使用文档

第一次使用，从[新手指南](GETTING_STARTED.md)开始。这里的教程对应 v0.8.0。

| 你想做什么 | 阅读哪篇 |
| --- | --- |
| 选设备和连接方式 | [选择使用方式](CHOOSE_YOUR_SETUP.md) |
| 安装到电脑或服务器 | [Windows](INSTALL_WINDOWS.md) · [Linux / 服务器](INSTALL_LINUX.md) |
| 用 Android 聊天或本机运行 | [Android 说明](INSTALL_ANDROID.md) |
| 连接酒馆或 Operit | [插件安装与配置](PLUGIN_SETUP.md) |
| 连接其他支持 MCP 的应用 | [MCP 配置](MCP.md) |
| 配置模型和后台整理 | [模型与后台整理](AUTOMATIC_MEMORY.md) |
| 查接口和导入格式 | [使用与接口手册](USAGE.md) |
| 给自己的应用做自动召回 | [召回 API](RECALL_API.md) · [应用接入](INTEGRATION.md) |
| 写本地开发示例 | [开发与模型替身](DEVELOPMENT.md) |
| 备份、恢复和升级 | [维护说明](MAINTENANCE.md) |
| 排查安装问题 | [安装常见问题](INSTALLATION_NOTES.md) |
| 看版本变化 | [更新记录](CHANGELOG.md) |

不配置模型 Key，也可以导入、浏览、检索和手工整理。插件只负责把已有记忆交给聊天应用；新聊天同步需要应用另行接入。
