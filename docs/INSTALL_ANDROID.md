# Android：连接服务或在本机运行

**最省事的路线是：洄海装在电脑或服务器，手机聊天软件连接它。** 手机不需要另装一个洄海 APK。

## 手机连接已有服务

| 聊天软件 | 怎样连接 |
| --- | --- |
| Operit 1.12.2 | 导入洄海 toolpkg，在工具箱填写服务地址与专用召回凭据。 |
| SillyTavern 1.19.0 | 在酒馆服务端安装扩展，手机浏览器打开酒馆并填写扩展设置。 |
| 支持 Streamable HTTP MCP 的应用 | 填服务的 `/mcp` 地址与认证请求头，并在目标助手里启用工具。 |

具体步骤：[插件配置](PLUGIN_SETUP.md) · [MCP 配置](MCP.md)。

手机中的 `127.0.0.1` 指手机自己。服务在其他设备，就要使用手机可访问的地址和可信连接。两个插件负责召回已有记忆，不负责把新聊天自动导入。

## 只有手机，想在本机运行？

可以使用 Linux 工作区手动安装。以下菜单以 RikkaHub 的工作区为例，工作区仅是运行环境，并不赋予其他 App 自动注入能力。

1. 在 RikkaHub 打开「设置 → 扩展管理 → 工作区」，创建一个新工作区。
2. 安装 Rootfs，打开工作区终端。Rootfs 是运行 Linux 程序所需的基础环境。
3. 在 Ubuntu 工作区安装组件：

   ```bash
   apt-get update
   apt-get install -y python3 python3-venv python3-pip git
   ```

4. 按 [Linux Python 安装步骤](INSTALL_LINUX.md#用-python-安装)下载 v0.7.0、创建环境、安装并启动。
5. 手机浏览器打开 `http://127.0.0.1:8765`；如需 MCP，按 [MCP 教程](MCP.md)连接。

参考：[RikkaHub 工作区说明](https://docs.rikka-ai.com/zh/extensions/workspace)。

这条路线需要下载 Linux 环境与依赖、使用终端并手动启动服务。**目前不提供仅手机一键安装、自动常驻或换机恢复向导。** Android 省电和后台限制可能停止工作区；持续运行需结合设备设置自行管理。

## 停止与备份

终端按 `Ctrl+C` 停止服务。数据在启动时的 `--data` 目录，不在 MCP 配置里；删除 MCP 条目不会删除记忆。

按[维护说明](MAINTENANCE.md)停止全部写入后制作备份，再导出工作区文件。网盘只能保存备份，不会替你运行服务。完整手机换机流程和长期熄屏运行目前没有现成支持流程。
