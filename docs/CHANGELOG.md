# 更新记录

## v0.7.0

- 新增聊天前自动召回接口，根据当前消息查找记忆，并返回可加入模型上下文的文本。
- 提供 SillyTavern 和 Operit 插件 0.2.0，可在界面中填写服务地址、召回凭据和启用开关。
- 为 SillyTavern 1.19.0 的扩展设置、提示词插入接口，以及 Operit 1.12.2 的发送前插件接口做了适配。
- 新增专用召回凭据，可限制到指定 Agent、应用来源和通道，并支持撤销。
- 召回会过滤当前聊天中已经出现的内容，读取当前记忆版本；服务出错或等待超时，插件继续原聊天。
- 重写安装、插件、MCP、自动记忆和备份教程。

插件只负责读取记忆并附加到本轮请求。新聊天的保存需要应用单独接入同步接口。安装见[插件教程](PLUGIN_SETUP.md)，升级见[维护说明](MAINTENANCE.md)。

## v0.6.0

- 增加独立后台 worker，可定期整理已授权历史。
- 为 Writer、Gatekeeper、Reflection 接入模型服务，保存任务状态和用量。
- 保留人工修订内容，自动整理不覆盖人工修改。
- 模型用途可以分别配置，默认关闭；启动管理台不会自动调用模型。

## v0.5.0

- 增加 Streamable HTTP MCP，同一服务提供管理台、HTTP API 和 MCP。
- MCP 增加记忆、证据、历史导入、人工记住和修订工具，共九项工具。
- 增加中文入门教程与管理界面操作指引。
- 提供开发用的固定响应维护接口。真实模型后台整理在 v0.6.0 加入。

## v0.4.0

- 提供独立 Python 应用、Web 管理台和 HTTP API。
- 支持注册 Agent、授权来源、导入和搜索历史、人工保留记忆。
- 支持记忆来源与修订、水系组织、数据备份和恢复。
- 提供四项 stdio MCP 读取工具。

旧版源代码和下载文件保留在 [GitHub Releases](https://github.com/yuyu1838309000-cmd/Thalemora/releases)。当前教程按 v0.7.0 编写。
