# 更新记录

## v0.10.0

- 改了约定，自动整理可以更新原来的记忆，并留下旧版本。只说「这次」的事也更容易和长期习惯分清。
- 找原话时可以按说话人和时间查。聊天软件提供了前文时，「后面那个」这样的追问也能接着上句找。
- 已接入每日摘要的应用可以引用当日原句，保留说话人。按天、周、月整理需要应用配置模型和后台任务。
- 可以导入 ChatGPT 导出包里的文字聊天。先预览数量，再决定是否保存。通过支持 MCP 的聊天软件，还能直接记笔记、把卡片移进回收站或恢复。
- 酒馆和 Operit 插件更新到 0.2.1。一条消息即使超过 200 字也可以查记忆，上限为 8192 个字符。

[第一次安装](GETTING_STARTED.md) · [旧版升级](MAINTENANCE.md) · [插件下载与安装](PLUGIN_SETUP.md)

## v0.9.0

- 新增公共记忆选择，结合话题、短句上文、事实变化和原话语境提供回忆；保留当前修订与来源证据，便于回查。
- 为主动联系、寻找活动和行动前核对提供记忆材料；工具的拦截、批准与执行仍由聊天应用负责。
- 可信宿主可接入自然浮现和余韵，并复用已有反思、激活信号；触发和最终消息拼接由宿主控制。
- 收紧普通短句与历史原话的相关性判断，减少泛词碰巧重合时带出不相干旧记忆的情况。
- 有可信原话证据的持续事项可附加进行中、更新、结束状态，沿用原有修订与来源核验；需要宿主接线，不自动追踪所有聊天。

仅具备主动调用条件的客户端或开发者可接入新能力。既有 SillyTavern / Operit 插件没有自动升级到新宿主能力，新聊天同步仍需单独接线。完整模型回复的 Token、费用及延迟请在接入方的真实聊天环境中观察。

下载 [v0.9.0](https://github.com/Nereviay/Thalemora/releases/tag/v0.9.0)，安装和升级步骤见[新手指南](GETTING_STARTED.md)与[维护说明](MAINTENANCE.md)。

## v0.8.1

- 为选中的历史原话补充同一会话中有依据的前后文，并保留说话者和来源；缺少可靠会话或时间信息时不猜测补全。
- 适配 Python 3.15 的依赖安装。

## v0.8.0

- 更正或删除过的原话，不再继续作为当前事实自动召回；新一版原话也不会再被旧引用挡住。
- 后台补充的记忆（如“又养了一只鹦鹉”）现在能被读到、被检索到，也能在证据里查到它来自哪句话。
- 一条记忆只有当前来源仍有效时才自动使用；来源失效后资料仍保留，旧结论不会被静默当成现状。
- 修复并发重建索引时可能把旧向量写进新正文的问题，重启后缺向量会自动补齐。
- 相似度改用真实余弦计算；模型服务不可用时退回关键词检索，继续给出发言可用的记忆，而不是整轮失败。
- **行为变化**：管理接口默认只处理当前应用来源的记忆，跨应用查看需显式选择全局管理。旧工具若依赖原来的隐式全局读取，请改为显式全局模式。
- 调用次数预算为硬上限；token 预算只是阈值，并发请求下可能略超，实际费用以服务商账单为准。

已有数据目录可直接沿用，无需迁移；旧索引缓存会自动重建。升级步骤见[维护说明](MAINTENANCE.md)。

## v0.7.0

- 新增聊天前自动召回接口，根据当前消息查找记忆，并返回可加入模型上下文的文本。
- 提供 SillyTavern 和 Operit 插件 0.2.0，可在界面中填写服务地址、召回凭据和启用开关。
- 为 SillyTavern 1.19.0 的扩展设置、提示词插入接口，以及 Operit 1.12.2 的发送前插件接口做了适配。
- 新增专用召回凭据，可限制到指定 Agent、应用来源和通道，并支持撤销。
- 召回会过滤当前聊天中已经出现的内容，读取当前记忆版本；服务出错或等待超时，插件继续原聊天。
- 重写安装、插件、MCP、自动记忆和备份教程。

插件只负责读取记忆并附加到本轮请求。新聊天的保存需要应用单独接入同步接口。安装见[插件教程](PLUGIN_SETUP.md)，升级见[维护说明](MAINTENANCE.md)。

## v0.6.0

- 增加独立后台 worker，可定期整理已授权历史。
- 为 Writer、Gatekeeper、Reflection 接入模型服务，保存任务状态和用量。
- 保留人工修订内容，自动整理不覆盖人工修改。
- 模型用途可以分别配置，默认关闭；启动管理台不会自动调用模型。

## v0.5.0

- 增加 Streamable HTTP MCP，同一服务提供管理台、HTTP API 和 MCP。
- MCP 增加记忆、证据、历史导入、人工记住和修订工具，共九项工具。
- 增加中文入门教程与管理界面操作指引。
- 提供开发用的固定响应维护接口。真实模型后台整理在 v0.6.0 加入。

## v0.4.0

- 提供独立 Python 应用、Web 管理台和 HTTP API。
- 支持注册 Agent、授权来源、导入和搜索历史、人工保留记忆。
- 支持记忆来源与修订、水系组织、数据备份和恢复。
- 提供四项 stdio MCP 读取工具。

旧版源代码和下载文件保留在 [GitHub Releases](https://github.com/Nereviay/Thalemora/releases)。安装与插件教程以当前正式版 v0.10.0 为准；新能力的接入条件见[应用接入](INTEGRATION.md)。
